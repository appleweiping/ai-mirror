System prompt and settings

Reasoning models (GPT-5/6, newer Claude) reject a custom temperature, so the proxy leaves it out for them. Their hidden reasoning also counts as output tokens.

API keys

A key is only sent when a column uses that provider. One OpenRouter key covers models from many vendors.

Prices used for the cost estimate

Privacy. Your prompt and the key for each column go from this page to the site's /api/chat edge function, which forwards them to that provider and streams the answer back. The function's code does not log or store prompts or keys (Vercel keeps its usual request logs: path, status and time). Keys stay in this tab's sessionStorage unless you tick Remember keys, which saves them in this browser's localStorage. What you send is then covered by each provider's own data policy.

About the numbers. Times are measured in your browser, so they include the hop through the edge function. Token counts come from the provider when it reports them; "~" marks an estimate from text length. Costs are list-price estimates, not your bill.
